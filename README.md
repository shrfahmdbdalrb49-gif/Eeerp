# شرف ERP - نظام إدارة الصيدليات

نظام SaaS متعدد المستأجرين لإدارة سلاسل الصيدليات والصيدليات الفردية.

## المميزات
- تجربة Desktop-First احترافية
- دعم كامل للغة العربية (RTL)
- نظام محاسبي متكامل
- إدارة المخزون والتشغيلات (FEFO)
- نقطة بيع سريعة (POS)
- إدارة التأمين الصحي والمطالبات

## التقنيات
- Frontend: Vue.js 3 + Vite
- Backend: Node.js + Express
- Database: PostgreSQL 16
- Styling: Custom Design System

## البدء
```bash
npm install
npm run dev
```
